# 🍢 钵钵鸡「越吃越上头」改造方案

> 玩家反馈:好玩,但关卡少、不够上瘾。
> 本文档给出诊断、参考国内小游戏(羊了个羊 / 开心消消乐 / 抓大鹅 / 跳一跳 / 合成大西瓜)的成熟套路,
> 并把每个系统落到现有代码文件与具体参数上。
>
> 状态:**P0~P2 已全部实现**(无限碗/续命/放水/每日一钵/分享卡/竹签币/任务/成就称号图鉴/皮肤商店/特殊签×5/修饰词×5/新食材×4),
> 经 Playwright 58 项冒烟验证。P3(微信小游戏/在线排行榜)仍为展望。
> 与设计的实现差异:碗型难度用「堆叠松紧」(倒签半径)实现,不改碗的静态碰撞体——物理效果相同、风险为零;
> 签数 52 封顶后由堆叠逐碗收紧接棒难度曲线。

---

## 1. 一句话诊断

**缺的不是关卡,是循环。**

物理堆叠 + 压签判定的核心玩法天生具备无限重玩性——每一钵的堆叠都不一样(生成本来就是随机的,见 `game.ts` 的 `spawnNow()`)。玩家说"关卡少",真正的意思是:

- 3 个碗吃完(约 6 分钟)就**没有下一个目标**了;
- 输了没有"就差一点"的挽留,赢了没有"下一碗更精彩"的预告;
- 存档里只有星星和最高分(`store.ts` 的 `SaveData`),**没有任何隔天回来的理由**。

所以方向不是手工堆关卡,而是把已有的随机生成升级成**带难度曲线的无限进度**,再补上**留存钩子**。

## 2. 国内小游戏套路速查

| 游戏 | 核心套路 | 本作怎么落地 |
| --- | --- | --- |
| 开心消消乐 | 无限第 N 关 + 锯齿难度 + 连败暗中放水 | §3 无限碗 + §7 动态放水 |
| 羊了个羊 | 每日一关全球同题 + 近失挫败 + 分享炫耀 | §5 每日一钵 + 分享卡 |
| 抓大鹅(本作灵感) | 实体手感 + 道具救场 + 关卡装饰变化 | §4 续命 + §6 特殊签/修饰碗 |
| 跳一跳 | 分数攀比 + 好友排行 | §5 分享卡,P3 微信小游戏 |
| 合成大西瓜 | 一局一个明确目标 + 截图传播 | 结算屏改造(§9) |
| 各类小游戏通用 | 签到 / 每日任务 / 收集图鉴 / 皮肤 | §5 每日三件事 + §6 图鉴称号 + §6 小卖部 |

**明确不抄的**(反套路声明,见 §10):体力限制、强制广告、付费抽卡、弹窗轰炸。这是给成都友友的爱心之作,借的是**留存结构**,不是**黑暗模式**。

## 3. 框架:四层循环,现在只有一层

```
① 秒级循环(一次拔签):  瞄准 → 拔/被压 → 连击/惩罚     ✅ 已经很爽,不动
② 局级循环(一碗):      开局 → 清盘/超时 → 结算 → 再来   ⚠️ 结算屏没有钩子
③ 天级循环(隔天回来):  每日挑战 / 任务 / 连续打卡        ❌ 完全没有
④ 社交循环(拉人攀比):  分享卡 / 排行榜                  ❌ 完全没有
```

下面每个系统都标注它补的是哪层循环。

## 4. 系统 A:无限碗 —— "今天吃到第几碗?"(② 局级)

把固定 4 关(`config.ts` 的 `LEVELS`)改成**无限进度**:第 1/2/3 碗就是现有的小碗/中碗/大盆(兼做教学),从第 4 碗起由生成器接管。原「流水席」保留为独立冲分模式。

### 4.1 生成器(替换 `LEVELS` 查表)

```ts
// config.ts:LEVELS 数组 → bowlForStage(n) 函数,seed = mulberry32(n * 7919)
function bowlForStage(n: number): LevelDef {
  // 签数:约每碗 +2~3,60 封顶(性能上限,60×~6 碰撞体 Rapier 无压力)
  // 时间预算:每签秒数 5.6 → 3.3 平滑收紧: spb = max(3.3, 5.6 - 0.08*(n-1))
  // 金签:1 + floor(n/6),封顶 3
  // 帮吃:2 + floor(n/8),封顶 4(死锁免费送保留)
}
```

### 4.2 锯齿难度(消消乐核心:紧一碗,松一碗)

- `n % 4 == 0` → **回血碗**:签数 −6、金签 +1,轻松拿 3 星,给玩家"我变强了"的错觉;
- `n % 5 == 0` → **宴席碗**(小 Boss):签数 ×1.3、时间 ×1.15、帮吃 +1、双金签,过关全屏烟花 + 称号进度;
- 其余碗按 4.1 平滑爬坡。**难度感来自对比,不是绝对值。**

### 4.3 碗型即难度(本作独有的物理杠杆)

`BOWL` 目前是全局常量(`config.ts:2`),改成随关卡可变:

| 碗型 | 参数变化 | 难度效果 |
| --- | --- | --- |
| 浅盆(现状) | 基准 | 堆叠 2~3 层 |
| 深碗 | `innerTopR` −20%,签数不变 | 堆更深,压签关系更复杂 |
| 大盆(宴席) | `innerTopR` +25% | 铺得开,爽快清盘 |

签数以外多了一个不伤帧率的难度维度,而且视觉上每碗都不一样。

### 4.4 命名与仪式感

程序化起名:`[风格池] × [碗型池]`,如「藤椒·深碗」「牛油·大盆」「雾都·转桌」。名字是廉价的新鲜感,配合现有的 `serve()` 上桌播报(`i18n.ts`)零成本升级。

### 4.5 存档变化

```ts
// store.ts SaveData 新增
stage: number;            // 已通过的最高碗号 —— 核心进度数字
failStreak: Record<number, number>;  // 放水用(§7)
```

**心理学:碗号本身就是炫耀资本。**"我吃到第 47 碗"和"我三关全 3 星"完全不是一个量级的谈资。

## 5. 系统 B:每日一钵 + 分享卡(③ 天级 + ④ 社交)

### 5.1 每日一钵(羊了个羊套路,Wordle 结构)

- seed = 当地日期 `YYYYMMDD` → `mulberry32`(`textures.ts` 已有)→ 关卡参数 + 倒签序列全球一致;
- 固定规则:中等难度 + 1 个修饰词(§6.2),**每天只能正式挑战一次**(练习不限,成绩不记);
- 连续打卡日历:连 3 天 / 7 天 / 30 天给竹签币和皮肤(§6.3);
- 注:物理沉降在不同设备/帧率下会有微小差异,倒签序列一致已足够构成"全球同题"的心理事实。顺手把 `physics.ts` 的 `step()` 改成固定步长累加器,一致性会更好(本来也该做)。

### 5.2 分享卡(纯前端,零依赖)

结算屏一键生成 Canvas 图(540×864,朋友圈竖图)+ 复制 emoji 文本:

```
🍢 钵钵鸡 · 每日一钵 8月2日
🥢🥢🥢🥢🥢 38/38 光盘!
⏱️ 剩23s ★★★ 🔥最高连击×9
我吃到第 47 碗「藤椒·深碗」,你呢?
👉 bellabao1111.github.io/boboji
```

Canvas 画碗 + 签 + 数据,延续零素材传统。**没有后端也能做社交攀比**——把排行榜外包给微信群。

### 5.3 每日三件事(轻任务)

从池子里每天转出 3 个:拔 50 签 / 达成一次 8 连击 / 吃 3 根金签 / 不用帮吃过一碗 / 3 分钟内光盘。奖励竹签币。全部挂在现有事件上(`succeedPick` / 结算),实现成本极低,是性价比最高的隔天回访理由。

## 6. 系统 C:收集、变化与商店(②③ 循环的燃料)

### 6.1 特殊签种(把金签泛化)

`Skewer` 已有 `golden` 标记与 `flash()` 基建(`skewer.ts`),泛化成 `kind` 字段:

| 签种 | 规则 | 上瘾点 | 解锁碗号 |
| --- | --- | --- | --- |
| 🌟 金签(已有) | +8s +300 分 | 惊喜 | — |
| 🧊 冰冻签 | 连点 2 次(第一下敲冰),不扣时 | 节奏变化 | 5 |
| 🧨 炮仗签 | 挂 10s 引线,拔掉 +5s,炸了 −5s + 震屏 | 优先级决策 | 7 |
| 🌶️ 魔鬼椒签 | 拔后 5 秒内全场得分 ×2 | 风险收益 | 9 |
| 👻 幽灵签 | 半透明时隐时现,显形才能拔 | 时机把握 | 12 |
| 🧲 磁签 | 连带吃掉压着它的一根签 | 爽点道具 | 15 |

**逐碗解锁 = 内容滴灌**:结算屏预告"第 7 碗解锁 🧨 炮仗签",这就是"再来一碗"的理由。

### 6.2 修饰词碗(第 7 碗起,seed 决定 0~2 个)

| 修饰词 | 实现 | 落点 |
| --- | --- | --- |
| 雾锅 | 蒸汽 sprite 变浓,遮住底层 | `effects.ts` 已有蒸汽 |
| 深夜食堂 | 主光调暗 + 指针跟随聚光 | `environment.ts` 灯光 |
| 转桌 | 碗体缓慢自转 | `physics.ts` kinematic |
| 麻辣双倍 | 分数 ×2,时间 ×0.85 | `RULES` 覆盖 |
| 大胃王 | 吃签动画 1.5 倍速,纯爽 | `game.ts` 动画时长 |

### 6.3 竹签币 + 小卖部(全部装饰/便利,不卖数值)

- **来源**:拔 1 签 = 1 币,金签 8 币,过关 = 碗号×5,3 星 ×1.5,任务 30~80 币;
- **去处**:续命第 2 次(88 币)、开局多带 1 次帮吃、**皮肤**——青花瓷碗 / 砂锅 / 不锈钢盆、清汤 / 番茄 / 青花椒汤底(`broth.ts` shader 换色即可)、签筒与桌面纹理(`textures.ts`);
- 定价让一件皮肤 ≈ 2~5 天游戏量,**制造"再玩两碗就够了"的回访,而不是付费墙**。

### 6.4 图鉴、成就、称号

- **食材图鉴**:9 种食材记录累计吃掉数;新食材(毛肚 / 黄喉 / 年糕 / 脑花)随碗数入池,每种约 30 行程序化建模(`foods.ts`),继续滴灌;
- **成就**:累计 1000 签 / 单碗零失误 / 15 连击 / 一局双金签……
- **称号**(按累计拔签数):100 拔签学徒 → 500 串场熟客 → 2000 签王之王 → 10000 钵钵鸡非遗传承人。称号印在分享卡上——**收集系统最终都要通到炫耀出口**。

## 7. 系统 D:续命 + 动态放水(把最挫败的时刻变成最上瘾的时刻)

### 7.1 差一点续命(近失挽留)

超时判负时若剩签 ≤ max(3, 总数×15%):弹「老板再送你 10 秒!」,5 秒倒计时按钮制造紧迫感。**每碗第 1 次免费,第 2 次 88 竹签币,最多 2 次。**落点:`game.ts` 的 `finish(false)` 之前拦截。

商业小游戏在这里放广告;我们免费送,拿到的是同样的"就差一点→再来一次"多巴胺,没有任何反感。

### 7.2 连败暗中放水(消消乐从不承认但一直在做)

同一碗连败 2 次:下次时间 +8%;连败 3 次:+15% 且被压惩罚 2s→1.5s;连败 4 次:开局送 1 次帮吃。过关即清零,**永不告知玩家**。落点:`startLevel()` 读 `save.failStreak`。

### 7.3 失败文案

结算屏区分"差得远"和"就差 2 签":后者必须大字显示「就差 2 签!老板都替你着急」——近失感是重开率的第一驱动力。

## 8. 系统 E:结算屏 = 上瘾枢纽(② 局级)

现在的结算屏(`ui.ts` 的 `showResult`)是终点,要改成**下一局的起点**:

1. 大号「第 N 碗」进度戳 + 连续打卡角标;
2. **下一碗预告卡**:名字 + 修饰词 + "解锁 🧨 炮仗签" 预告;
3. 任务进度打钩动画(3 件事完成 2 件 → 强烈想清掉第 3 件);
4. 竹签币入账滚动数字;
5. 主按钮永远是「再来一碗」,一次点击直接开局(消消乐式零摩擦续玩);
6. 分享卡按钮(§5.2)。

## 9. P3 展望:微信小游戏(④ 社交的终局)

抓大鹅 / 跳一跳 / 羊了个羊爆火的真正引擎是**微信关系链排行榜**。技术上:three.js 有 weapp-adapter 方案、微信支持 WASM(Rapier 可跑)、包体 gzip 后 ~1.5MB 远低于 4MB 主包限制、好友榜走开放数据域;真正的门槛是国内发行需要软著与备案。近期替代:网页版加一个 Cloudflare Workers 免费全球榜(可选),或干脆只靠分享卡把攀比外包给群聊。

## 10. 反套路声明(明确不做)

| 不做 | 为什么 |
| --- | --- |
| 体力/次数限制 | 那是为了卖广告和内购;我们无货可卖,纯增流失 |
| 强制/激励广告 | 同上,伤"致敬友友"的品牌 |
| 付费与抽卡 | 竹签币只从玩里来 |
| 弹窗轰炸/红点焦虑 | 每日内容用"预告"呈现,不用"惩罚"逼迫 |

## 12. 怎么验证有效

没有后端,先用本地代理指标(顺手做成玩家可见的「我的战绩」页,一鱼两吃):

- 单次会话吃几碗(目标:从现在的 ≤4 → 8+);
- 连续打卡天数分布;
- 续命使用率与续命后过关率(过关率 ~50% 说明近失阈值调对了);
- 分享卡生成次数。

真要看留存曲线,再考虑接极轻量统计(Cloudflare 免费档),不急。
