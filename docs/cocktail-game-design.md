# 🍸 摇摇酒馆 · 调酒小游戏设计草案

> BoBoJi 的姊妹作：一款部署在 GitHub Pages 上的调酒小游戏。
> 像塞尔达做饭一样自由组合材料发现配方，但比它多一步——**你发明的酒会真的上菜单，被客人点名回购**。

状态：构思阶段草案（未开工）。本文档是玩法提案，供讨论与迭代。

---

## 1. 一句话概念

**深夜小酒馆里，客人不点酒名、只说心情；你凭手感倒酒、摇壶、搅拌，任何组合都能出一杯"作品"——调中经典鸡尾酒解锁图鉴，调出没人见过的就由你命名、挂上菜单，成为回头客的心头好。**

## 2. 设计支柱（延续 BoBoJi 的 DNA）

1. **自由组合、判定兜底**：像塞尔达把任何食材丢进锅都有结果，任何倒进摇壶的东西都能出一杯酒——没有"非法操作"，只有好喝、难喝和搞笑。
2. **真手感**：倒酒看倾角、摇壶真的摇（手机摇设备）、搅拌画圈、分层控速。互动不是点按钮，是"手上活儿"。
3. **失败即内容**：喷射的可乐、把客人放倒的"闷倒驴"、谜之液体——全部收进"黑历史图鉴"，失败可收藏。
4. **零外部素材**：所有画面 Canvas/Shader 程序化绘制、所有音效 WebAudio 合成，延续 BoBoJi 的传统，仓库里不放一张图。
5. **中文默认、双语切换**，localStorage 存进度，移动端优先。

## 3. 核心创新点（为什么新颖）

市面上的调酒游戏大致三类，我们和它们都不同：

| 已有游戏 | 玩法本质 | 我们的差异 |
| --- | --- | --- |
| Bartender: The Right Mix | 纯试错，配方是唯一答案 | 我们有属性引擎，任何组合都有意义的结果 |
| VA-11 Hall-A | 照着配方表抄，重叙事 | 我们不给配方，靠实验发现；叙事只是轻佐料 |
| 塞尔达做饭 | 自由组合+图鉴+失败料理 | 我们在此之上加"自创酒上菜单"与真实调酒手感 |

四个核心创新：

1. **属性引擎**（塞尔达式核心）：每杯酒不是查表结果，而是由材料属性向量实时计算出来的（烈/甜/酸/苦/气泡/颜色/温度）。经典配方只是属性空间里的"命名点位"。
2. **自创酒上菜单**：调出未命名的组合 → 游戏根据成分自动起名（同配方永远同名，可复现）→ 客人喝了喜欢会问"这叫什么？"→ 你命名 → 挂上小黑板 → 之后的常客会**点名回购你发明的酒**。玩家的实验变成游戏内容，这是塞尔达做饭没有的成就感。
3. **模糊点单**：客人不报酒名，说的是人话——"来杯苦一点的，今天被老板骂了"、"清爽带气泡、别太醉"。你要把"心情"翻译成配方。多个答案都能及格，命中经典鸡尾酒有惊喜彩蛋。
4. **每日特调**：日期作随机种子，每天一位全球相同的奇葩客人+限定材料，成绩生成 emoji 卡片一键分享（类 Wordle），纯前端无后端，GitHub Pages 就能跑。

## 4. 核心循环

```
一杯酒的循环（约 30~60 秒）：
选杯 → 加冰 → 倒材料（控倾角/控量）→ 技法（摇/搅/直调/捣/分层）→ 装饰
   → 判定动画（客人举杯）→ 反应&小费 → 图鉴/菜单更新

一晚营业的循环（约 5~8 分钟）：
开店 → 5~8 位客人依次上门 → 打烊结算（营业额/新发现/图鉴进度）
   → 用赚的钱解锁新酒瓶/工具/杯子 → 下一晚（主题夜：雨夜/周五夜/失恋之夜…）
```

三种模式：

| 模式 | 定位 |
| --- | --- |
| 🌙 营业模式 | 主线。一晚一晚开店，客人驱动学习曲线，赚钱解锁材料 |
| 🧪 自由调酒台 | 塞尔达的锅。无客人无计时，随便造，专心刷图鉴 |
| 📅 每日特调 | 日期种子挑战，限定材料+奇葩需求，emoji 分享成绩 |

### 5.2 技法修正

| 技法 | 操作 | 效果 |
| --- | --- | --- |
| 直调 Build | 直接倒进杯 | 保留分层，不稀释 |
| 搅拌 Stir | 画圈，有转速表 | 混匀+轻稀释，保持清澈（Martini/Negroni 必须搅） |
| 摇和 Shake | 手机真摇/桌面甩鼠标 | 混匀+降温+稀释+起泡沫（Sour 类必须摇）；**摇碳酸=喷射事故** |
| 捣 Muddle | 按住研杵捣几下 | 释放薄荷/青柠/水果香（Mojito 之魂） |
| 分层 Layer | 沿吧勺慢倒，倾角保持绿区 | 按密度出分层（B-52、日出渐变）；倒快了层塌 |
| 火焰 🔥 | 高阶解锁 | 表演分+焦香（火焰 B-52），失败=糊味进黑历史 |

### 5.3 判定流程（一杯酒倒完之后）

1. **查配方表**：材料集合命中 + 各项比例在容差内 + 技法正确 → 判为该经典鸡尾酒。
   比例误差 ±15% 内 ★★★，±30% ★★，有型无神 ★。技法错了扣星+吐槽（"马提尼是要搅的呀朋友"）。
2. **没命中** → 属性引擎汇总成一杯**自创酒**：按成分 hash 自动起名（词库组合：颜色/口感/诗意词，如"琥珀色的踌躇"、"薄荷味的加班费"）。同配方永远同名——可复现、可传播。
3. **灾难判定**（进黑历史图鉴）：摇碳酸→喷泉喷客人一脸；≥3 种基酒纯混→"闷倒驴"，客人喝完滑到桌下被保安抬走；蛋清不摇→"生蛋液"；苦精倒半瓶→"中药"。搞笑动画+小额扣分，不惩罚探索。

### 5.4 客人的"点单语言"

需求 = 属性区间 + 情境台词。举例：

| 客人台词 | 隐含属性需求 | 满分答案举例 |
| --- | --- | --- |
| "苦一点，我想清醒地难过" | 苦≥6，烈≥5 | Negroni；自创苦酒也能及格 |
| "清爽！带气泡！待会还要开会" | 气泡≥6，烈≤3 | 无酒精 Mojito、汤力特调 |
| "红色的，要好看，我发朋友圈" | 颜色=红系，颜值分 | Tequila Sunrise、自创分层酒 |
| "最烈的，别废话" | 烈≥9 | Martini；纯伏特加也行但小费少 |
| "上次那杯…叫'加班费'的还有吗" | 点名你的自创酒 | 复刻成功=双倍小费 |

客人性格库（首发 8 种）：下班社畜、文艺青年、健身达人（只喝无酒精）、老饕（唯一会直接报酒名考你的人）、失恋的人、情侣（要一对颜色成 CP 的酒）、已微醺者（再要烈的→你可以偷偷给无酒精假装是烈的，良心玩法彩蛋）、**成都友友**（要"巴适的"，钵钵鸡宇宙联动）。

## 6. 互动手感（好玩的物理细节）

- **倒酒**：按住酒瓶拖到杯口，手指上下移动控制倾角，倾角决定流速，液面实时上涨。默认有量酒器刻度辅助；关掉辅助进入 **Free Pour 硬核模式**，全凭手感，成功有额外"手感分"。
- **摇壶**：手机用 DeviceMotion 真实摇晃（iOS 弹权限，拒绝则退化为快速滑动），桌面甩鼠标或连打空格。摇到位时摇壶结霜、屏幕呵出白气。
- **搅拌**：手指/鼠标画圈，有优雅的转速表——太快酒液浑浊，客人皱眉。
- **分层**：慢速倾倒沿吧勺流下，保持倾角在绿色区间，密度差正确才能出清晰分层。
- **装饰**：青柠角/橄榄/樱桃/橙皮/薄荷枝/小伞自由拖拽摆放，摆完可拍照出分享卡。
- **声音彩蛋**：倒酒声的音调随液面升高而变高（真实的亥姆霍兹共鸣物理），冰块 clink、摇壶沙沙节奏、成功时五声音阶——和 BoBoJi 的连击音阶同宗，宇宙统一听感。

## 7. 图鉴与进度

- **三本图鉴**：📖 经典酒图鉴（约 24 款，未解锁显示剪影+谜语提示，如"三样材料，大力摇，杯口一圈盐"）｜🏷️ 本店特调（你命名上菜单的自创酒）｜🗑️ 黑历史（灾难合集，客人反应连拍）。
- **解锁树**：开局 6 瓶（金酒/朗姆/伏特加/青柠汁/汤力水/糖浆）+ 摇壶。每晚营业额自选进货方向——买金巴利走苦系、买咖啡利口走甜系——玩家决定探索路径。工具（吧勺/研杵/分层勺/喷枪）和杯型（马天尼杯/古典杯/高球杯/子弹杯）逐步解锁。
- 星级和图鉴完成度给称号：学徒 → 调酒师 → 首席 → "深夜之神"。

## 8. 美术与音频方向（零素材）

- **场景**：深夜雨窗小酒馆。前景吧台+杯子是主角，背景霓虹灯牌、雨滴窗景视差滚动。暖钨丝灯 + 霓虹青/粉点缀，底色深紫夜（#1a1420 一系）。
- **液体是主角**：杯中液体用 shader 画——分层渐变、倒酒时的弹性液面波动、上浮气泡粒子、杯壁冷凝水珠、冰块折射高光。颜色混合用 OKLCH 插值，混出来的颜色永远好看。
- **UI**：手写粉笔字菜单黑板、纸质图鉴翻页动画。复用 BoBoJi 的中文字体子集方案（站酷快乐体/马善政）。
- **音频**：WebAudio 合成 lo-fi 双和弦 pad + 黑胶底噪 + 滤波噪声雨声；所有音效现场合成，零音频文件。

## 9. 技术方案

| 项 | 方案 |
| --- | --- |
| 栈 | Vite + TypeScript，无框架（同 BoBoJi），复用 i18n.ts / store.ts / sfx.ts 的模式 |
| 渲染 | **推荐 2D**：WebGL shader 画液体+玻璃（液体表现比 3D 更可控更美），DOM+CSS 做 UI/图鉴/菜单。不需要 Rapier，不需要 Three——倾倒用贝塞尔流+粒子，液面用弹簧-正弦波即可。包体预计 <300KB gzip |
| 布局 | 手机竖屏优先（杯子居中、瓶架下方两排横滑），桌面横屏吧台全景，响应式 |
| 存档 | localStorage：图鉴/自创菜单/进度/语言（同 store.ts 模式） |
| 每日特调 | 日期字符串做 PRNG 种子，纯前端，无后端 |
| 部署 | 同款 GitHub Actions → Pages workflow，`base: './'` |
| 仓库 | 建议新开仓库（独立 Pages 地址）；原型可先在本仓库分支上搭 |

## 10. 分期计划

- **MVP（先能玩）**：自由调酒台 + 8 种材料 + 倒/摇/搅三技法 + 属性引擎 + 12 款经典配方判定 + 自动命名 + 图鉴 + 双语框架。→ 这一步完成就已经是"塞尔达式调酒沙盒"。
